## How This Directory Works

Each file in this directory is a **corpus entry** for one tradition. Each entry is structured uniformly so the engine can query any of them through the same pipeline:

- **Primary texts** and their canonical scholarly editions
- **Linguistic references** (grammar, dictionary, onomastic scholarship)
- **Pattern axes** — the tradition's claims on Origin, Journey, Claim, Name, Season, Landscape, Diaspora, Lineage, Voice
- **Declarative naming practice** — how the tradition treats names
- **Diaspora doctrine** — how the tradition treats descendants born far from the homeland
- **Scholarly sources** for verification

## Adding a New Entry

Follow the template structure of an existing Tier 1 entry (recommended: [shona_zimbabwean.md](shona_zimbabwean.md) or [gaelic_irish.md](gaelic_irish.md)). Requirements:

1. Documented foundational text(s) with canonical editions
2. Linguistic references (grammar + dictionary + onomastics)
3. Pattern axes filled in with direct-cited claims from the tradition
4. Declarative naming practice described
5. Diaspora doctrine addressed
6. Scholarly bibliography

An entry is ready for Tier 1 use when a published finding has been produced against it.

*The catalogue grows as the engine runs. Every query either matches an existing tradition or reveals a new one to build.*
